# উপায় (upay) AI Shield & FinTech Super-App

An AI-powered, fraud-resilient, and financial-inclusion mobile financial services (MFS) super-app built on top of a Bangladeshi MFS ecosystem, faithfully mirroring the native **upay** brand identity (`#0B4DA2` deep blue and `#FFD600` gold yellow).

This platform combines real-time transaction safety checks, Gemini-powered multilingual intelligence, parametric climate microinsurance, P2P escrow, community rotating savings (Somiti), regional dialect voice payments, automated mandate rules, and garment worker payroll protection under the Bangladesh Labor Act 2006.

---

## 🌟 Comprehensive Feature Catalog

### 1. 🛡️ Safe AI Shield & Pre-Transaction Risk Check
- **Deterministic 0–100 Risk Engine**: Evaluates amount anomalies, velocity, unknown recipients, odd late-night hours, and cross-wallet syndicates.
- **Explainable Advice**: Plain Bangla explanations generated by Gemini (`@google/genai`) using privacy-masked data.
- **Cooling-Off Period & Verification**: 15-second countdown on high-risk transfers, 3-point security checklist, and ৳10 test transfer recommendation.
- **Human-in-the-Loop**: The AI never approves or blocks transactions autonomously; the user always retains the final decision.
- **Scam Message & Link Checker**: Evaluates SMS texts and suspicious URLs for lottery scams, fake bKash/Nagad/upay schemes, and malicious APKs.
- **Scam Call Simulator**: Audio training simulation with realistic speech synthesis for impersonation calls, lottery fees, and emergency extortion.

### 2. 🎙️ Live Voice Assistant (Gemini Live API)
- Real-time bidirectional Bengali audio streaming over WebSocket (`ws://localhost:3000/ws/live`).
- PCM 16kHz audio capture/playback for natural, human-like voice conversations in everyday Bangla.

### 3. 🗣️ আঞ্চলিক ভাষা-সচেতন ভয়েস পে (Dialect-Aware Voice Layer)
- Browser Web Speech API (`bn-BD`) mic input with visualizer and text fallback.
- **Regional Dialect Normalization**: AI interprets standard Bangla and 4 major regional dialects into structured intents (action, recipient, amount):
  - **চাটগাঁইয়া (Chattogram)**: *"রহিমরে পাঁচশ টিয়া পাঠাই দেও"*
  - **সিলেটি (Sylhet)**: *"করিমর গেসে এক হাজার টেকা পাঠাউক্কা"*
  - **নোয়াখাইল্লা (Noakhali)**: *"বিল্লাল ভাইরে আড়াইশ টেকা হাডাই দেন"*
  - **রংপুরিয়া (Rangpur)**: *"মজিদক দুইশ টেকা পাঠায় দেও বাহে"*
- **TTS Amount Confirmation**: Reads the transfer amount aloud using speech synthesis and displays large text before proceeding.
- **Mandatory PIN / Biometric Security**: Voice never triggers an automatic debit; requires an explicit 4-digit PIN or simulated biometric touch.

### 4. 📜 ম্যান্ডেট ওয়ালেট (Mandate Wallet: AI-Permissioned Payments)
- **Natural Language Parsing**: Accepts voice or text rules such as *"প্রতি মাসে গ্যাস বিল ১৫০০ টাকার নিচে হলে পরিশোধ করো"*.
- **AI Rule Parser Only**: Extracts biller, maximum limit, condition, and frequency into a structured JSON rule without executing payments.
- **Deterministic Rule Engine**: Plain TypeScript engine enforces the maximum ceiling and pauses/approves incoming bills strictly.
- **Interactive Bill Simulator**: Test incoming bills within or above the limit to verify approval or blocking reasons.
- **Execution & Audit Log**: Tracks approved and blocked bills with detailed deterministic reasons.

### 5. 👔 পে-স্লিপ অডিটর এবং ওয়েজ-ডে অর্কেস্ট্রেটর (Payslip Auditor & Wage-Day)
- **Payslip Auditor**:
  - Garment and factory workers enter or choose mock payslips (basic salary, overtime hours, deductions).
  - Simple Bangla explanations of salary calculation and allowances.
  - **Bangladesh Labor Act 2006 Compliance**: Evaluates legal overtime rate `(Basic / 208) * 2` and flags underpaid overtime hours or unexplained deductions.
- **Staggered Wage-Day Cash-Out**:
  - Staggered time slot allocation (e.g. *"আজ বিকাল ৪:১৫ - ৪:৪৫"*) to eliminate crowding at agent counters.
  - Agent-side view predicting physical cash demand per slot (e.g. 110 workers, ৳13.2 lakh) with a cash readiness checklist.

### 6. 🤝 ডিজিটাল সমিতি (Digital Somiti: ROSCA)
- Rotating savings and credit association for informal financial groups.
- **Fair Payout Order**: Game-theoretic auction and emergency need scoring to determine lottery payout sequences.
- **Early Warning System**: Identifies members at risk of default using transaction regularity scores.

### 7. 🔒 ট্রাস্টপে এসক্রো (TrustPay: P2P Merchant Escrow)
- Escrow protection for social commerce (Facebook / F-Commerce).
- Funds are safely locked until parcel delivery is confirmed via OTP or courier tracking.
- AI Merchant Trust Score and dispute resolution mediator.

### 8. 🗺️ হাইপারলোকাল লিকুইডিটি নেটওয়ার্ক (Hyperlocal Agent Liquidity)
- Live map of nearby MFS agents showing cash availability (Green/Yellow/Red status).
- AI liquidity demand forecasting for Eid and salary cycles.
- Agent-to-Agent (A2A) balance rebalancing to prevent cash-out stockouts.

### 9. 🌐 ক্রস-ওয়ালেট ফ্রড ডিফেন্স (Cross-Wallet Consortium)
- Inter-MFS fraud intelligence sharing (simulated consortium of bKash, Nagad, upay, Rocket).
- Identifies serial fraudsters opening new accounts under altered NID/SIM credentials.

### 10. 🌾 ক্লাইমেট-শিল্ড মাইক্রো-ইনস্যুরেন্স (ClimateShield)
- Parametric weather-index microinsurance for smallholder farmers and fishermen.
- Automated claim payouts triggered by satellite rainfall and temperature data without manual paperwork.

### 11. 🛂 অলটারনেটিভ ইনকাম পাসপোর্ট (Alternative Income Passport)
- Creditworthiness passport for gig economy workers (Uber/Pathao drivers, freelancers, street vendors).
- Generates downloadable verifiable income certificates for bank loan and microfinance applications.

### 12. 📊 স্মার্ট ফি অডিটর ও বান্ডেল অপ্টিমাইজার (Fee Auditor & Bundle Saver)
- Detailed breakdown of monthly cash-out fees with ATM vs. agent savings comparisons.
- Telco bundle optimizer recommending tailored data/talk-time packs based on actual usage.

### 13. 🌙 যাকাত ক্যালকুলেটর ও ঈদ খাম (Zakat & Digital Eidi)
- Precise Nisab-based Zakat calculator across gold, silver, cash, and business inventory.
- Direct donation to verified charity institutions.
- Gamified animated Eid envelopes (ঈদের সালামি খাম) with confetti celebrations.

### 14. 👓 এক্সেসিবিলিটি, অ্যানালিস্ট ড্যাশবোর্ড ও ফেয়ারনেস অডিট
- **Simple Mode**: High-contrast, large-font UI for elderly and rural users.
- **Analyst Queue**: Back-office dashboard for reviewing flagged transactions.
- **Fairness & Bias Audit**: Monitors false positives across demographic groups and Bangladeshi geographical divisions.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### 2. Installation
```bash
npm install
```

### 3. Environment Configuration
Ensure your `.env` contains:
```env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
```
*(In Google AI Studio Build, the `GEMINI_API_KEY` is provided automatically via runtime secrets).*

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Build for Production
```bash
npm run build
npm run start
```
