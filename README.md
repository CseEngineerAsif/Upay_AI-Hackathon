# Upay Safe (উপায় সেফ) — AI-Powered MFS Safety & Intelligence Layer

An AI-powered financial safety, risk intelligence, and financial wellness layer built on top of a Bangladeshi mobile financial service (MFS) application, styled to replicate the Upay mobile app.

---

## 🌟 Key Features

1. **Pixel-Perfect Upay UI**:
   - Signature Upay yellow (`#FFD600`) and deep blue (`#0B4DA2`) brand identity.
   - White splash screen with two-figure "U" logo and curved blue-grey swoosh line.
   - Exact login screen with 4-digit PIN pill, circular blue arrow button, and custom fixed on-screen numeric keypad.
   - Home screen with balance toggle pill, 4-column icon grid, promotional carousel, Upay payment grid, and raised center **BANGLA QR** button.
   - "আরো" (More) screen with grouped settings, support, account services, and policies.

2. **Pre-Transaction Safety Check (Core Differentiator)**:
   - Transparent rule-based TypeScript risk engine (0–100 score).
   - Real-time baseline comparison: amount anomaly, new recipient, odd late-night hours, high velocity, unrecognized device/location, flagged recipient database.
   - Colored risk meter with "কেন?" (Why?) explainability breakdown.
   - Plain Bangla & English safety advice generated by Gemini 3.8 Flash (`@google/genai`) using structured masked evidence (phones masked, zero PIN exposure, Zod schema validation).
   - High-risk cooling period countdown (15s), 3-point verification checklist, and small test payment suggestion (৳10).
   - **Human-Decision Boundary**: The AI never approves or denies payments autonomously. The user always makes the final choice.
   - Post-warning feedback recording ("এই সতর্কতা কি সহায়ক ছিল?") and scam confirmation.

3. **Scam Message & Link Checker**:
   - TF-IDF keyword scoring & heuristic URL analysis for phishing domains and malicious APKs.
   - Instant Bangla verdict with detected triggers and actionable recommendations.

4. **Financial Dashboard & Cash-Flow Forecast**:
   - Moving-average cash-flow projection for 7, 14, and 30 days.
   - Monthly category breakdown with Recharts pie chart and previous month comparison.
   - Explainable Financial Health Score (Savings ratio, Cash-out dependency, Stability).
   - Safe-to-Spend weekly estimate.
   - What-If Simulator with sliders for expense reduction %, income changes, and goal contributions.
   - Next-Best-Action recommendations with "Why this recommendation?" evidence.

5. **Goal Planner & Micro-Savings Round-Up**:
   - Automated savings planner (e.g. "৬ মাসে ৩০,০০০").
   - Micro-Savings Round-Up: Moves spare change from payments (e.g., ৳7 from a ৳53 bill) into an active savings goal.

6. **Trusted Guardian Network**:
   - Invite a family member by phone for high-risk payment alerts.
   - Conceals private recipient numbers to preserve user privacy.
   - Live cross-tab simulation via `BroadcastChannel` for instant dual-device demonstrations.

7. **Scam Call Simulator**:
   - Interactive phone call UI with realistic Bangla voice synthesis (`window.speechSynthesis`).
   - 3 scripted fraud scenarios (Fake Upay agent, lottery tax fee, hospital emergency extortion) with live keyword triggers.

8. **Bengali AI Chat Assistant ("উপায় সহকারী")**:
   - Answers questions like "গত মাসে খাবারে কত খরচ হয়েছে?" with natural Bengali financial insights.

9. **Analyst Queue & Admin Monitoring / Fairness Dashboard**:
   - Role-based analyst queue for reviewing, dismissing, or escalating flagged transactions.
   - Admin monitoring metrics: Precision, Recall, False-Positive Rate, Estimated ৳ Saved, latency.
   - Fairness audit comparing model accuracy across 6 Bangladeshi regions, 4 age brackets, and account tenures.

10. **Accessibility & Consent**:
    - **Simple Mode** toggle with enlarged typography and simplified language for vulnerable users.
    - Explicit AI safety data consent management.

## 🚀 Quick Start & Installation

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Ensure `GEMINI_API_KEY` is present. (AI Studio injects this automatically).

### 3. Run Development Server
```bash
npm run dev
```
The application will launch on `http://localhost:3000`.

## 🧪 Local Firebase Emulator Suite (No Billing Required)

To run the full backend offline using the Firebase Emulator Suite:

1. Install Firebase CLI:
   ```bash
   npm install -g firebase-tools
   ```
2. Start the Emulators:
   ```bash
   firebase emulators:start --only firestore,auth,functions
   ```
3. The emulators will run Firestore on `8080`, Auth on `9099`, and the Emulator UI on `4000`.
